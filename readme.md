# 🚌 Bus Tracking & Passenger Safety System

A **real-time bus tracking and passenger safety system** built using the **MERN stack**.

The project allows passengers to view bus information, routes, and live bus locations. Drivers can share their real-time location, which is transmitted to passengers using **Socket.IO**.

### 🚀 Main Technologies

* Node.js
* Express.js
* MongoDB
* Mongoose
* React.js
* Socket.IO
* JWT Authentication

### 🎯 Goal

The goal of this project is to make public transportation more **trackable, convenient, and safer** by providing real-time bus location tracking and useful passenger safety features.
